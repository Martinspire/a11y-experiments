Experience shaking

There are various illnesses that result in shaking. This page allows you to browse various videos of people who have trouble controlling their movements. Most famous is parkinson's disease, but there are many other illnesses that result in shaking.

The main issue

People with this illness have trouble interacting. They often misclick items and unintentionally click others. This demo consists of two parts, one where you experience shaking and are going to get through a few steps in order to submit a form. The effect is slightly increased to make it more difficult.

This demo is limited to web technologies. If you want to experience a deeper demo, please use a system implementation of shaky mouses. (links to follow)

There are solutions available to combat shaking like: SteadyMouse

Preparation

Since Javascript doesn't allow developers to override the mouse cursor position, it is unfortunately not possible to easily create a demo with working forms. There's a Canvas implementation (for gaming) but that doesn't work properly. So therefor the only solution to try this demo, is to install a tool, run the script and try it like that.

For windows users: we've created a simple exe that can do this and you can download it here: shaking.exe. It is created with a Tool called AutoIt which can be downloaded on their website We've used a script which you can also compile and edit yourself with this file: shaking.au3. When using it, press [home] to start the script and press [esc] to exit or [pause] to pause.
