Screen Reader

As expected Screen readers are a type of assistive technology that reads text that is displayed on the screen. They are used by people who are blind or visually impaired. Screen readers are a form of assistive technology that are essential for people who are blind or visually impaired. They are used to read text that is displayed on the screen, and they can also be used to navigate through websites and other applications.

Preparation

First, download a screen reader, install it and have it running. We recommend Chrome Screen Reader, an extension for any Chrome based browser. You can download it here. Important keys for using it, are the [Ctrl] + [Shift] keys. It acts as a modifyer to access various settings and navigate the page. Instead of just tabbing, you can use [Ctrl] + [Shift] + [Arrows] to navigate around the page to have it tell if something is a header or a list item and if so how many items are in the list.
Look at the video below how it works and how to use it:

Alternatively you can use NVDA (Non Visual Desktop Access) for Windows devices, which is a better tool than some of the native screen readers and can be used outside of the browser as well. You can download it here: https://www.nvaccess.org/download/. Be aware that it will play audio and start talking when you run the installer.

Once running you can adjust settings or use shortcuts. There is an overview of shortcuts here: https://www.nvaccess.org/files/nvdaTracAttachments/455/keycommands%20with%20laptop%20keyboard%20layout.html, but basically the most important ones are with [Insert] (the NVDA key). [Insert] + S switches modes so you can temporarily pause the voices or hold the Control key to ignore while you hold it.
You will find the NVDA icon in system tray for when you want to exit or change settings. You can also change voice settings, change from male to female, change speed and pitch, etc.

Be aware: once you run screen reader software, other software might pick up on that and behave differently. VSCode for example will switch and make sounds and whatnot. It will display a label on the bottom-right of the window indicating screen reader mode is enabled.
