Real world examples

Here we feature a few examples of real world scenarios and how they fail to make things clear for colorblind people.

Sources:

  • https://www.secretstache.com/blog/designing-for-color-blind-users/
  • https://econsultancy.com/considering-colour-blindness-in-ux-design-with-five-examples/

T-shirt colors on Amazon

The product picker for variants on Amazon fails to easily recognize what colors are used. We see a picture but it doesn't really tell us what color it is, until we hover over it or select the item. This is a common issue for colorblind people.

Lack of underline on links on Techcrunch

Techcrunch has a very clean design, but it lacks underlines on links. This makes it hard for colorblind people to see what is a link and what isn't. This is a common issue for colorblind people.

Errors on Facebook

Two examples on Facebook. The first has errors but they only show a red border, which is hard to tell apart for colorblind. The second has errors but they are still hard to see for colorblind people and only the exclamation mark gives it away.

Required fields in red

Required fields are marked in red, which is a common practice. But for colorblind people, this is hard to see. It's better to use a symbol.

Transparancy on images

Images with transparancy and text on top can be hard to see for colorblind people. Use a bigger contrast or avoid transparancy behind text entirely.

Poor chart design

Colors for charts are often hard to distinguish for colorblind people. Use patterns or symbols to make it easier to read. Or use a colorblind friendly palette. Or add labels to the items in the chart on the items direcly.

Did I like this post on Twitter/X


The like button on Twitter was red when you haven't liked it and gray when you have. This is hard to see for colorblind people. It's better to use a symbol or a different color.

How hot?

A menu with colors to indicate how hot something is. This is hard to see for colorblind people. It's better to use a symbols on top to make sure everybody is able to see how hot it is.
