Aria - the way to make the web accessible

ARIA (Accessible Rich Internet Applications) is a set of attributes that can be added to HTML elements to make web content more accessible to people with disabilities. ARIA is designed to work with existing web technologies, such as HTML, CSS, and JavaScript, to enhance the accessibility of web content.

ARIA attributes can be used to provide additional information about the structure and behavior of web content, making it easier for people with disabilities to navigate and interact with websites and web applications. ARIA attributes can be added to elements such as buttons, links, form fields, and images to provide information about their purpose, state, and role.

There are currently 22 aria attributes that can be used to enhance the accessibility of web content. Some of the most commonly used aria attributes include aria-label, aria-labelledby, aria-describedby, aria-hidden, aria-live, and aria-pressed. These attributes can be used to provide information about the purpose, state, and role of elements on a web page, making it easier for people with disabilities to understand and interact with the content.

Preferences

While Aria tags are mostly focused to attend the wishes of people with disabilities, there's also the group of users that may not be impaired, but has certain preferences that websites can apply. Think of Dark mode, font-sizes, showing subtitles, language (including right to left direction), date and time localisation and formatting. And many more.

Many of these items can be handled using CSS media queries or in Javascript (window.matchMedia('(prefers-color-scheme: dark)'))

  • @media (prefers-reduced-motion: reduce)
  • @media (prefers-contrast: more)
  • @media (prefers-color-scheme: dark)
  • @media (prefers-color-scheme: light)
  • @media (prefers-color-scheme: no-preference)
  • @media (prefers-reduced-data: reduce)
  • @media (prefers-reduced-transparency: reduce)
